# Repository instructions

These instructions apply to the entire repository.

## Language

- Use English for all new or modified repository content: code comments,
  docstrings, documentation, examples, test descriptions, and user-facing
  messages (including logs, warnings, and errors).
- Use English for new identifiers and file names.
- Write commit subjects and bodies in English. Use a concise, imperative
  subject that describes the change, for example: `Fix snapshot cleanup retry`.
- Write pull request titles and descriptions in English.
- When editing existing non-English text, translate the affected text into
  English while preserving its meaning and technical accuracy.
- Preserve proper names, external API names, and literal data that must remain
  unchanged for correctness. Do not rewrite existing commit history.
